## ✨ Features

- 🔍 Search any English word
- 📖 Word Meaning & Definition
- 🔊 Audio Pronunciation
- 📝 Part of Speech
- 💡 Example Sentences
- 🔗 Synonyms
- 🌙 Light/Dark Theme
- 📱 Fully Responsive Design

## 🛠️ Tech Stack

- React.js
- Vite
- CSS3
- Dictionary API
